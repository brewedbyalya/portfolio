Automation Experience

Zapier

Connecting tools together so repetitive tasks run on their own.

  • HubSpot + Google Calendar: when someone submits a HubSpot form, they are automatically added to a Google Calendar invite.
  • Google Sheets: when someone registers for something, a sheet updates itself. Triggers include HubSpot forms, changes to a HubSpot segment, or a new Stripe payment.
  • Slack: alerts sent to a reminder tab or a specific channel, triggered by a sheet update or a new registrant.
  • HubSpot workflows: HubSpot workflows only react to internal triggers, so Zapier catches the external trigger first and then enrols the person in the workflow.
  • Calendly + email: people who book a meeting automatically receive reminder emails.

HubSpot Workflows

Automated emails and messaging based on what contacts do.

  • Segments + emails: when someone enters a segment (often an active one) for the first time, they get an email. Often used when a lead status changes.
  • Forms + emails: anyone who fills out a HubSpot form gets a confirmation email.
  • Webhooks, forms, Twilio template + WhatsApp Business: a workflow that sent a WhatsApp message to everyone who completed a HubSpot form.
  • Email sequences: a series of emails scheduled days apart.

Google Apps Script

Scripts that replace manual work across Calendar, Sheets and Gmail.

  • Bulk calendar invites: a sheet lists each panel’s title, date, time and attendee emails, and the script creates every invite. The script also sets the description, Google Meet link, location and guest visibility, so speakers and panels no longer need invites created one by one.
  • Adding guests: a sheet of emails is added to an existing invite automatically.
  • Bulk email: sends emails to a list of addresses without emailing each person by hand.
  • Removing guests from large invites: once an invite passes 50 guests, emails can no longer be removed manually, so a script removes them.
  • Live API data: pulls data from an API into a Google Sheet.
